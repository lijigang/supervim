# 手工验收清单

这份清单汇总任务 1 到任务 15 里单元测试没有在真机上做过的项目。每一项都还不能标成通过。

在自己的 Mac 上按步骤操作。看到期望结果再勾选。做不到就保持未勾选，不要改规格，也不要把「没测到」写成「已经达标」。授权之后免重启、`f` 的 200ms 和 90% 覆盖率，都仍然是要求；测不到就继续写「未验证」。

准备：从 Release 的 DMG 把 Supervim 拖进「应用程序」并打开。辅助功能和输入监控都已允许，除非某一步故意在缺权限时做。菜单栏应显示 Normal、Insert 或 Paused，Dock 里没有图标。

## 安装

- [ ] **DMG 拖拽安装**
  - 操作：打开 `Supervim-<版本>.dmg`。把 `Supervim.app` 拖到窗口里的 Applications 快捷方式。从「应用程序」文件夹启动。
  - 期望：映像里同时有 `Supervim.app` 和 Applications 链接。拖过去之后，`/Applications/Supervim.app` 可以打开。菜单栏出现状态，Dock 不出现图标。

- [ ] **未签名应用第一次打开**
  - 操作：如果系统拦住了第一次打开，依次试这三种里还没用过的做法：在 Finder 里右键（或按住 Control 点按）选择「打开」并确认；打开「系统设置」→「隐私与安全性」，选择「仍要打开」；在终端执行 `xattr -dr com.apple.quarantine /Applications/Supervim.app` 后再打开。
  - 期望：至少一种做法能把应用打开。应用仍然没有开发者签名，也没有公证。ad-hoc 签名只让 Apple Silicon 有机会启动它，不表示 Gatekeeper 已经信任它。

## 权限引导与免重启

- [ ] **缺权限时出现引导**
  - 操作：在系统设置里关掉 Supervim 的辅助功能或输入监控，再打开 Supervim。
  - 期望：出现引导，只列出仍缺的那一项，并提供打开对应系统设置面板的链接。菜单里出现 Permissions。这时按 `j` 或 `f` 不会被吞掉。进程不崩溃。

- [ ] **设置链接能打开对应面板**
  - 操作：在引导里分别打开辅助功能和输入监控的链接。
  - 期望：系统设置打开到对应的隐私面板，而不是一个无关页面。

- [ ] **两项都允许之后开始工作**
  - 操作：把两项都允许，回到 Supervim，使用引导里的重新检测，或让应用重新变为活动状态。不要先退出应用。
  - 期望：规格希望引导关掉，并且当前进程立刻可以扫描焦点、安装钩子。把实际看到的写成「不用退出就生效」或「必须退出再打开才生效」。后者保持未验证，不改规格第 10 条。

- [ ] **重新构建之后可能要重新授权**
  - 操作：用 `scripts/assemble-app.sh release 0.1.0` 重新构建，替换「应用程序」里的 `Supervim.app`，再打开。
  - 期望：记录系统有没有再次要求辅助功能或输入监控。未签名二进制更换之后，可能要再授权一次。看到要重新授权，并不算失败。

## 普通模式与 f

- [ ] **标签在 200ms 内出现**
  - 操作：在 Safari、Finder 和系统设置里各打开一个有按钮或链接的窗口。焦点不在可编辑文字上。按 `f`，同时用秒表或屏幕录制看标签出现的时间。
  - 期望：三个应用里，标签都在按下 `f` 之后 200ms 内出现。做不到就保持未测，不改规格。

- [ ] **可访问按钮和链接覆盖率高于 90%**
  - 操作：在上面三个应用里，数出辅助功能能读到的按钮和链接，再数出 `f` 实际标出来的数量。
  - 期望：每个应用里，标出来的数量除以可访问的按钮和链接，高于 90%。这是界面覆盖率，不是源码行覆盖率。

- [ ] **标签盖住对应控件，点击打中它，原来的窗口保持焦点**
  - 操作：在 Finder 或 Safari 里按 `f`，看标签是否落在对应控件上。键入一个完整标签。
  - 期望：左键点在该控件上，标签消失，回到普通模式。浮层出现时，原来的窗口仍然是焦点，Supervim 不把自己变成前台。`F` 是按住 Command 的点击，不是右键菜单。

## 不吞字

- [ ] **微信、备忘录、Safari 地址栏**
  - 操作：在微信的输入框、备忘录的正文、Safari 的地址栏里输入一段普通文字，包括 `f`、`j`、`?` 和 `Ctrl+Option+V` 里的字母。
  - 期望：字符按原样进入这些输入框，一个都不被 Supervim 吃掉。焦点可编辑时菜单栏显示 Insert。按 `Esc` 之后离开输入焦点，回到普通模式。

## 滚动、gi、放过下一键、yy

- [ ] **滚动**
  - 操作：在 Safari 的一个可滚动页面上，指针放在页面里，依次按 `j`、`k`、`h`、`l`、`d`、`u`、`gg`、`G`。再找一个没有可滚动区域的窗口，按 `j`。
  - 期望：方向与 Vimium 一致：`j` 下、`k` 上、`h` 左、`l` 右，`d` / `u` 半页，`gg` 到顶，`G` 到底。选不到可滚动区域时，`j` 交给前台应用，页面不被乱滚。

- [ ] **`gi`**
  - 操作：在有输入框的网页上，焦点先放在页面正文。按 `gi`。再在一个没有输入框的窗口按 `gi`。
  - 期望：有输入框时，焦点进到第一个输入框，菜单栏变成 Insert，随后的文字不被吞。没有输入框时留在普通模式，不把焦点扔到一个不相关的控件上。

- [ ] **`Ctrl+]`**
  - 操作：在普通模式按 `Ctrl+]`，紧接着按 `j`，再按一次 `j`。
  - 期望：第一下 `j` 交给前台应用，不滚动。再下一键恢复成 Supervim 的滚动。

- [ ] **`yy`**
  - 操作：在 Safari 和一个 Chromium 家族浏览器（例如 Chrome）里打开一个网址，按 `yy`，再粘贴。然后在「文本编辑」或「备忘录」里按 `yy`。
  - 期望：浏览器里剪贴板出现地址栏里的文字。非承诺应用里不发出 Command+`L` 或 Command+`C`，地址栏或选区不被改掉。Firefox 和 Opera 不在承诺名单里。

## 暂停热键与排除列表

- [ ] **`Ctrl+Option+V`**
  - 操作：焦点放在 Safari 的页面上，不是在输入框里。按 `Ctrl+Option+V`。再按 `j`。再按一次 `Ctrl+Option+V`，再按 `j`。
  - 期望：第一次之后菜单栏变成 Paused，`j` 交给页面。第二次回到 Normal，`j` 重新滚动。这个热键走的是事件钩子，不是单独注册的全局热键。焦点未知、权限缺失，或前台应用在排除列表里时，它不应该吞键。把真机上是否每次都能暂停记下来；单元测试没有标成通过。

- [ ] **排除列表**
  - 操作：打开「终端」。确认它的 bundle id 是默认排除的 `com.apple.Terminal`。在终端里输入 `j`、`f` 和 `Ctrl+Option+V`。再到设置里加入当前前台应用，切到那个应用按 `j`，然后从列表里移除它再按 `j`。
  - 期望：终端里的字符原样留下，暂停键也不切换暂停。加入排除的应用同样完全不被拦截。移除之后，普通模式的 `j` 恢复滚动。iTerm2（`com.googlecode.iterm2`）和 GNU Emacs（`org.gnu.Emacs`）同样排除。

## 帮助

- [ ] **帮助面板**
  - 操作：在普通模式按 `?`。再按 `f`。再按 `?` 打开，然后按 `Esc`。在输入框里按 `?`。
  - 期望：第一次 `?` 打开帮助，不抢走当前窗口的焦点。`/`、`F`、`?` 三行能读到与 Vimium 不同。开始 `f` 时帮助先收起，再出现标签。再按 `?` 或在普通模式按 `Esc` 会关闭帮助。输入框里的 `?` 进入文字，不打开帮助。

## 登录时启动

- [ ] **在「应用程序」里打开登录启动**
  - 操作：确认 Supervim 是从 `/Applications` 打开的。在设置里勾上 Launch at Login。打开「系统设置」里的登录项。再取消勾选，重新看登录项。退出并重新登录一次 macOS，只在勾选状态下做。
  - 期望：勾选后，登录项里出现 Supervim，或者系统把它标成还需要你允许。取消勾选后，这一项消失。重新登录后，勾选状态下菜单栏应用会自己起来。进程不崩溃。

- [ ] **不在「应用程序」里时失败可见**
  - 操作：从仓库的 `build/Supervim.app` 直接打开，不要先拖进「应用程序」。在设置里勾上 Launch at Login。
  - 期望：设置里出现把应用移进 Applications 的提示。应用不崩溃。偏好可以仍然保存为打开；移进「应用程序」并从那里再打开之后，再按这个偏好登记。

## 其他仍未在真机上看过的目标

这些来自宪法或各任务的测试记录。勾选同样只表示你在自己的机器上看到了期望结果。

- [ ] **空闲资源**
  - 操作：打开 Supervim，不要按键，用「活动监视器」看一两分钟。
  - 期望：空闲时 CPU 接近零，内存低于 50MB。这是宪法里的目标，不是已经测量过的成绩。

- [ ] **帮助和标签不抢焦点、文字能看清**
  - 操作：在主屏幕上打开帮助，再打开 `f` 的标签。
  - 期望：面板透明、不激活、鼠标点得穿。帮助文字在屏幕上可读。标签坐标和控件重合。

- [ ] **历史、标签、关闭、新建、刷新**
  - 操作：在 Safari 里依次按 `H`、`L`、`J`、`K`、`x`、`t`、`r`。
  - 期望：后退、前进、上一个标签、下一个标签、关闭、新建、刷新，对应 Command 加 `[`、`]`、Shift+`[`、Shift+`]`、`W`、`T`、`R`。`J` 是上一个标签，`K` 是下一个。
