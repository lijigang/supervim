# Supervim 宪法

状态：已批准。任务 1 原样收录这些原则，没有把目标改写成已经测到的结果。

后续实现和评审都以此为准。冲突时，丢字比漏掉快捷键更严重，隐私约束优先于功能完整。

## 1. 原生与轻量

只用 Swift、AppKit 和系统框架。不用 Electron。空闲时 CPU 接近零。内存目标低于 50MB。

这是目标，不是本任务已经测量过的成绩。

## 2. 不干扰

当前焦点能不能编辑如果是未知的，按键必须原样放过。丢掉用户正在输入的文字，比漏掉一个快捷键更严重。

## 3. 默认 Vimium

默认按键和行为跟随 Vimium。凡是偏离，都要写进文档。

## 4. 测试先行

先写会失败的测试，再写实现。纯逻辑做单元测试。系统接口放在协议后面，测试使用替身，不直接碰真实系统。

## 5. 隐私

应用运行时不联网，不记录、不收集击键。只使用辅助功能（Accessibility）和输入监控（Input Monitoring）。

这条约束的是运行中的应用。CI 和构建机器可以联网。

## 6. 主干上的可交付形态

进入主干的功能，最终都要能在 macOS 上构建、测试，并提供可下载的 DMG。

按已批准排期，DMG 流水线是任务 15。任务 1 不制作 DMG。

## 7. 一个任务一个 PR

一个任务对应一个 PR。当前任务经过评审、并且所有者确认之后，才能开始下一个任务。
